# Enterprise SIEM & SOAR Platform

Real-time SIEM and SOAR platform built with Python for threat monitoring, incident response automation, and security analytics visualization.

## Features

* Real-time firewall log monitoring
* VirusTotal threat intelligence integration
* GeoIP threat mapping
* Interactive SOC dashboard
* Automated malicious IP blocking
* Threat analytics visualization
* Incident triage system
* Simulated SOC attack telemetry

## Technologies

* Python
* CustomTkinter
* Matplotlib
* REST APIs
* TkinterMapView
* Multithreading
